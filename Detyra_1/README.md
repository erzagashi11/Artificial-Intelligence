**Course:** Artificial Intelligence

| # | Problem | Algorithm | Folder | Language |
|---|---|---|---|---|
| 1 | Social Golfers Problem | DFS with Backtracking | [`1_SocialGolfers/`](1_SocialGolfers/) | Python |

For problems 1–3 the assignment requires:
1. Model the problem
2. Describe the representation of the problem (variables, domain, etc.)
3. Formulate the objective function
4. Calculate the landscape
5. Implement the corresponding algorithm

Each of the folders 1–3 contains:
- `README.md` with the theoretical part (model, representation, objective function, landscape) and the results
- the Python solution as a single `.py` file

Problem 4 is delivered as a single PDF: [`4_SearchTrees/Search_Trees.pdf`](4_SearchTrees/Search_Trees.pdf).
